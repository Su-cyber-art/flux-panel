# 1.5.10：shadcn-vue 导航与转发管理改版

本版本将导航、转发管理页及相关弹层迁移到 shadcn-vue，使用黑白灰主题、
紧凑表格和抽屉表单，支持深色、浅色及跟随系统外观。

## 变更

- 桌面导航支持折叠；手机和平板使用抽屉导航，改善窄屏下的操作空间。
- 转发列表增加搜索、隧道与运行状态筛选、分页，并保留分组和排序功能。
- 创建与编辑使用侧边抽屉，保留端口实时校验、多目标和负载策略设置。
- 启用状态与节点同步状态分开展示，支持异常重试；请求失败后仍会继续轮询
  未完成的同步任务，避免一次网络波动使同步状态停止更新。
- 统一地址复制、诊断、导入导出、删除确认和修改密码弹层。
- 将转发页面拆分为列表、表单和业务逻辑模块；组件源码保留在仓库中，
  便于后续调整和扩展。
- 增加独立的本地模拟预览命令，生产部署继续使用真实后端接口。

## 范围与升级

这是前端分阶段迁移的第一版。概览、隧道、节点、用户等其余页面仍使用
Naive UI，并应用统一的中性主题。

安装脚本和 Docker Compose 的使用方式不变，无数据库结构变更。
本版本没有新的后端或节点业务逻辑改动；已经运行 1.5.9 的节点无需因为
本次界面改版额外升级。

## 验证

- 依赖干净安装、TypeScript 类型检查和生产构建通过。
- 生产依赖审计未发现漏洞。
- 使用本地模拟接口验证创建、启停、同步重试、诊断、导入导出、删除、
  分页和排序，以及请求失败后的同步刷新恢复。
- 检查桌面、平板、手机布局和深浅色切换。

本次界面验收未连接真实 Java 后端和节点，原生手机 WebView 仍需真机验证。
诊断依然使用 TCP 检查，不能据此确认 UDP 可达性。
