# 1.5.14：修复验证码校验请求的时间格式

修复 1.5.13 中遗漏的校验请求适配：验证码 SDK 使用 Date 记录开始、结束
时间，直接 JSON 序列化后变为日期字符串，而后端 Tianai 1.5.5 的字段为
Long，导致 Cannot deserialize value / JSON parse error。

## 变更

- 提交校验请求前，将 startTime、stopTime 转为毫秒时间戳。
- 非法或缺失的时间在前端提示重试，不向后端提交错误数据。
- 保留尺寸和浮点轨迹数据，不修改服务端验证码与二次验证规则。
- 前后端测试共用校验请求样本，验证序列化结果与实际 Java DTO 一致。

## 验证与升级

11 项前端测试、类型检查、生产构建和生产依赖审计通过。
2 项实际 Java DTO 测试通过：旧日期字符串可复现解析失败，毫秒时间戳请求
可正确解析时间、尺寸和轨迹字段。完整线上验证码登录流程尚未重新验证。

本版本修复前端提交格式，无数据库或节点转发逻辑变更，节点无需因此升级。
