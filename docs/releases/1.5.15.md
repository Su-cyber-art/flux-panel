# 1.5.15：恢复登录错误提示

修复更换提示组件后遗漏 vue-sonner 样式，导致错误信息无法正常以浮层显示
的问题。登录失败时，具体原因同时保留在登录表单内，直到用户编辑或重试。

## 变更

- 加载 vue-sonner 必需的定位、层级和动画样式，恢复全局提示显示。
- 账号或密码错误、验证码请求失败、网络异常等信息在登录表单内持续展示。
- 新增登录页回归测试，覆盖验证码成功后携带凭证提交登录，以及登录失败
  时的反馈和重试流程。

## 验证与范围

13 项前端回归测试、类型检查、生产构建和生产依赖审计通过。
生产 CSS 已检查包含提示浮层的固定定位规则。

本次修复错误反馈的可见性，不代表已确认此前线上登录失败的具体原因。
验证码校验、密码校验和后端鉴权规则保持不变，无数据库或节点升级要求。
