# 1.5.12：修复手机端弹窗内容与按钮裁切

修复诊断、地址列表、导入导出和账户表单在小屏或横屏下内容过高，导致底部
按钮被裁切的问题。长内容单独滚动，标题与底部操作保留完整空间。

## 变更

- 统一普通弹窗和确认框的视口高度上限与滚动兜底。
- 修复诊断弹窗手机端的“关闭”“重新检查”按钮显示不全。
- 地址列表、导入导出、修改账户表单使用独立内容滚动区。
- 转发抽屉、导航抽屉使用动态视口高度，避免底部操作被长表单挤压。
- 节点、隧道、用户、限速页面的 14 个旧版卡片弹窗统一约束高度，内容滚动
  时保留标题和底部操作区。

## 验证

使用 macOS Safari 加载实际应用，在 320×568、390×620、844×390 和
1280×720 的受限视口下检查代表性弹窗。覆盖三十条地址、三行导出按钮、
多条导入结果、管理长表单、诊断结果和删除确认框。

类型检查、生产构建和生产依赖审计通过。此次验证不等同于 iPhone 真机
软键盘与浏览器工具栏动态变化的完整测试；详细记录见前端 design-qa.md。

## 升级

本版本仅调整前端布局，无数据库、后端接口或节点转发逻辑变更。
已经运行 1.5.9 或更高版本的节点无需因本次界面修复额外升级。
