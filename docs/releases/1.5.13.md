# 1.5.13：修复启用验证码后的登录流程

修复旧验证码渲染 SDK 与 Tianai 1.5.x 后端响应格式不兼容，导致验证码
无法初始化的问题。生成响应经过适配后交给渲染器，校验响应和服务端二次
验证保持不变。

## 变更

- 适配滑块、旋转、拼接和文字点选四种验证码生成响应。
- 验证码请求增加超时、HTTP 错误和异常响应处理，失败后恢复登录按钮。
- 关闭、刷新或离开页面时取消请求，忽略旧响应及延迟回调。
- 等待 Vue 挂载容器后初始化，避免固定延时产生竞态。
- 修正 SDK 异步返回值、关闭后的空值访问和轨迹中的模板尺寸字段。
- CI 与发布流程增加验证码协议和生命周期回归检查。

## 验证与升级

9 项回归测试、类型检查、生产构建和生产依赖审计通过。测试覆盖协议适配、
错误响应、超时、关闭后的迟到响应和验证凭证处理。

线上接口探测返回 HTTP 403，浏览器联调未完成，因此尚未验证真实登录全过程。
本版本不修改数据库、后端校验规则或节点转发逻辑，节点无需因本次修复升级。
